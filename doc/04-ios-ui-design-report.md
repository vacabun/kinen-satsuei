# 記念撮影｜iOS 界面与交互设计报告

2026-11-21 · 设计提案

## 1. 设计方向

把应用设计成一本可以随时翻阅的私人纪念册。打开时先看到一段值得回看的记忆。想记录时，拇指能直接按到底栏中央的添加按钮。扫描、归档、写回忆分别在最合适的时机完成。

视觉以黑、白、灰为主，保留照片原色。可爱感来自最初的爱心拍立得 Logo、柔和的圆角、小尺寸的日期标签和略带纸张质感的留白。拍立得照片本身保留实体边框，列表与编辑工具采用平整、克制的表面。成员头像和两颗应援色点提供个性，应用的主要按钮仍使用黑白配色。

### 现状与改版重点

| 现有 iOS 界面 | 改版处理 |
| --- | --- |
| 首页把最近笔记、最近媒体和成员收藏都显示为列表分区 | 第一屏突出一条有内容的回忆。近期媒体改用缩略网格，成员收藏显示姓名、头像和张数 |
| 底栏中央添加由普通 Tab 触发 | 保留居中布局，扩大快门式按钮的视觉权重。打开添加面板时维持原页面选中状态 |
| 拍立得扫描已经具备加粗轮廓、自动模式和手动模式 | 沿用这些能力，补齐稳定进度、未检测状态和重拍回路，让取景时的反馈可预测 |
| 拍立得预览已有校正工具及归属表单 | 调整为照片、检查工具、成员或团体、日期、保存的顺序 |
| 成员已有头像和双应援色；收藏已有年度格子 | 统一成员资料在设置、收藏和拍摄归档中的显示；让格子可以解释、筛选和清除 |
| 笔记与 Git 功能以表单和列表呈现 | 笔记阅读面采用更清晰的排版，Git 以连接状态和下一步操作组织 |

## 2. 导航与首页

### 全局底栏

```text
    首页        笔记         ＋         收藏        设置
                           添加
```

四个目的地保留各自的导航栈、搜索和滚动位置。中央按钮是独立动作，打开半高添加面板，关闭后回到原位置。深层详情保留系统返回手势。相机、四角校正和笔记编辑使用独立的全屏或模态流程，给底部工具留出空间。横屏与大屏延续相同的任务顺序，工具区随安全区重排。

添加面板按使用频率排列入口。「扫描拍立得」作为首项，「从相册导入」「拍摄照片或视频」随后。在笔记详情中使用「添加媒体」时，面板显示当前归属，并允许变更。导入多个项目时，由预览队列逐项检查，支持把日期或归属应用到选中的项目，并明确显示会影响几项。

### 首页第一屏

```text
記念撮影                                   搜索
┌─────────────────────────────────────────┐
│                 最近回忆的封面             │
│  大阪 Live                               │
│  11 月 21 日 · Live                       │
└─────────────────────────────────────────┘
最近媒体                                查看全部
[ 拍立得 ]     [ 合影 ]      [ 视频 0:18 ]
成员收藏                                查看全部
[头像] 成员名  ● ●                       24 张
```

- 标题使用「記念撮影」字标。简洁的应用标识使用第一版爱心拍立得，沿用现有放大后的图案比例。
- 首卡取最近有内容的已完成笔记，封面优先使用用户指定图像。没有封面时使用纯文字版式。只有媒体时，首个内容区直接呈现媒体网格。
- 首页搜索覆盖笔记、成员、团体和媒体备注。结果按类别分组，点开结果后返回时保留搜索词和滚动位置。
- 空库只给两个行动入口。「扫描第一张拍立得」进入相机流程，「写一篇笔记」直达编辑器。两者保存成功后，首页自然显示新增内容。

## 3. 拍立得扫描与预览

### 取景

相机画面铺满屏幕。上方放关闭与「自动／手动」切换，下方放状态、快门和相册入口。首次进入默认自动，两种模式均保留立即按下快门的能力。单轮扫描内保留用户选择的拍摄模式。

| 状态 | 画面表现 |
| --- | --- |
| 寻找边缘 | 显示低对比引导框和提示「把拍立得四角放进画面」 |
| 检测到边缘 | 检测轮廓采用约 5 pt 白线与约 9 pt 深色外描边，随四角移动 |
| 自动模式稳定中 | 快门外环显示稳定进度，状态提示「保持稳定」。轮廓移动或离开画面时取消进度 |
| 手动模式 | 保留检测轮廓，提示「已检测到边缘 · 按快门拍摄」 |
| 已触发快门 | 短暂反馈并锁定触发，随后进入预览。合并近乎同时发生的手动与自动触发 |
| 无权限、相机不可用 | 显示原因，并提供「打开系统设置」或「从相册导入」 |

### 保存前预览

```text
返回                 拍立得预览                重拍
┌─────────────────────────────────────────┐
│               完整拍立得图像               │
└─────────────────────────────────────────┘
 原图 / 校正图          调整四角          旋转
 归属                    选择成员或团体    ›
 拍摄日期                今天             ›
 回忆                    添加文字         ›
                [ 保存拍立得 ]
```

- 校正成功时默认展示校正图。预览完整保留实体边框和签名区域。无法校正时直接显示原图，允许手动拖四角。校正视图提供放大和微调，确认后返回表单原位置。
- 归属为成员或团体二选一。选择面板支持搜索；新增成员打开同一套资料表单，保存成员后自动选中，并保留当前照片、日期与回忆。新增团体沿用轻量的名称输入。
- 「拍摄日期」默认今天，可直接点击更正为实体拍立得所对应的日期。照片、视频或合影可选择「日期未知」。回忆为选填项。
- 底部主按钮靠近拇指；归属缺失时点保存可直接定位需要填写的行。保存中显示进行状态，失败时保留图片和填写内容供重试。保存后显示「查看拍立得」，拍摄入口同时提供「继续扫描」。
- 文件名只用于内部归档，预览、列表、详情和编辑表单都使用成员、团体和日期来识别记录。

## 4. 笔记、Live 与旅行

手机端正文编辑的详细方案见[卡片编辑器交互设计](05-mobile-note-editor-design.md)，其中包含卡片排序和独立的媒体选择流程。

笔记列表优先显示草稿和更新内容。草稿独立成区，打开后回到输入位置。已完成笔记有「全部／普通笔记／合影回忆／Live／旅行」筛选。记录卡只显示标题、时间、类型和必要封面。

| 任务 | 页面组织 |
| --- | --- |
| 写笔记 | 标题和日期置顶。正文采用「编辑／预览」切换，键盘工具栏提供标题、列表、引用和插入媒体。底部状态显示正在保存草稿、草稿已保存或保存失败 |
| 看合影回忆 | 先读标题、日期和正文，再看合影或拍立得。由媒体详情创建回忆时自动关联当前媒体 |
| 看 Live | 日期、地点和所属旅行在标题下方。现场视频和照片集中展示，相关合影回忆另成一组 |
| 看旅行 | 起止日期和封面置顶。正文后接按天分组的时间线，每日混排行程、Live 和合影回忆 |
| 调整归属 | 在详情的「移动」面板选择有效上级，或选择「设为独立记录」。同一个子记录也能从笔记列表直接打开 |

行程同日按时间排序，无时间的项目保留编辑顺序。修改旅行日期后，超出范围的已有项目仍可从「待调整」找到。编辑界面使用系统文本输入，保留中日文输入法的候选与组合过程。预览支持 Markdown 与内嵌媒体，缺失附件显示可读标题及原因。点「完成」是明确的发布动作。发布失败保留草稿。

## 5. 收藏、年度格子与成员

收藏首页先显示全库张数，再提供「成员／团体／全部拍立得」三个筛选和统一搜索。进入成员页后，头像、姓名、两颗应援色点与收藏总量组成紧凑的页头。统计区在图像网格上方，可以折叠。照片保留原比例，列表使用统一的网格占位尺寸以减少滚动跳动。

### 年度格子

- 以周为列、星期为行，使用年度选择器和月份标记，呈现类似 GitHub 贡献图的布局。初次打开定位到近期数据，小屏可横滑查看整年。提供清晰的低至高色阶图例，固定档位为 0、1、2–3、4–7、8+ 张，便于跨年比较。
- 点某日显示完整日期与数量，并筛选下方的照片网格。选中格用描边标记，网格上方显示日期筛选和「清除」。没有记录的日期也有明确的零张反馈。
- 默认口径为拍摄时间，可切换入库时间。标题标明当前口径。未知拍摄日期独立列出。总量按媒体记录计算，同一实体的原图、校正图与笔记引用共计一张。
- VoiceOver 和大字体保留「按日期查看」入口。可用日期列表完成同样的查找和筛选。

### 成员资料

成员管理使用独立资料卡。顶部圆形头像可从相册选择、更换或移除，空头像显示姓名首字或人物图标；下方先录入姓名，再选择「应援色一」与「应援色二」。两个色位独立保存、独立清除，**可设置成相同颜色**。选择器显示色点和色值，未设颜色时明确标记。两个色位相同时仍显示两个色点。成员列表、收藏页和媒体归属面板使用同一套头像与色点样式。

在拍摄流程里，姓名填好即可保存，头像和应援色可以之后从设置补充。改名后保留既有的拍立得和笔记引用。重名时优先显示头像，以及有数据时的团体或别名。

## 6. 设置、资料库与 Git

设置首页按「当前资料库」「成员与团体」「Git 同步」组织。资料库页面显示当前库与空间使用，提供切换、导出文件夹、从文件夹恢复。预计耗时较长的动作使用可见的进行状态和结果。跨库切换后，首页与搜索同时切换到新库。

Git 连接分成四步。填写 SSH 地址和分支，选择或生成密钥，核对服务器指纹，最后选择同步范围并确认。同步首页显示当前库、最近成功时间、待同步数量和主按钮「同步」。私钥在系统凭据区管理，状态页仅显示公钥与指纹。同步前解释「仅笔记和元数据」与「包含照片和视频」的恢复差别。成员头像属于成员资料，随元数据同步。

| 状态 | 界面反馈与可执行操作 |
| --- | --- |
| 首次连接 | 显示地址和指纹，核对后才继续；可取消 |
| 指纹变化 | 并列显示原指纹与新指纹，暂停同步并提供重新核验入口 |
| 远端已有资料 | 预览资料库名称、笔记数、媒体数和缺失附件，再确认恢复为独立资料库 |
| 有同步冲突 | 按笔记、成员或媒体分组；显示双方版本、变更字段，支持选择并逐项确认 |
| 离线或认证失败 | 保留本地浏览编辑，显示最近成功时间和具体的重试或查看密钥入口 |
| 附件缺失或过大 | 在媒体详情与同步状态显示原因，提供查看、导出或稍后重试 |

## 7. 视觉与组件规范

| 项目 | 设计规格 |
| --- | --- |
| 浅色 | 背景 `#F6F5F2`，卡片 `#FFFFFF`，正文 `#181817`，辅助文字 `#575652`，装饰分割线 `#DCDAD5` |
| 深色 | 背景 `#151514`，卡片 `#222221`，正文 `#F6F5F2`，辅助文字 `#B9B7B1`，装饰分割线 `#41403D` |
| 主按钮 | 浅色用近黑底和白字，深色用白底和近黑字。每个操作阶段突出一个主按钮。次要动作用文字或描边 |
| 字体 | 使用系统字体及中日文系统回退。页面标题默认 28 pt、区块标题 18 pt、正文 17 pt，日期和状态默认 13 pt，全部跟随动态字体 |
| 间距 | 4 pt 基础栅格；默认页边距 20 pt，小屏 16 pt；卡片内边距 16 pt；主要区块间距 24 pt |
| 圆角与图标 | 封面卡 20 pt、媒体卡 12 pt、主要按钮 16 pt。使用统一线重的系统图标。圆形限于头像、快门和中央添加按钮 |
| 图像 | 保留原始颜色。列表照片用适度裁切，拍立得详情、校正和预览完整显示四边。视频缩略图显示播放图标与时长 |
| 动效 | 首选系统转场及简短保存反馈；开启减弱动态效果时采用淡入或即时状态更新 |
| 可访问性 | 常规触控目标至少 44 × 44 pt；正文文字与背景对比目标至少 4.5:1。状态同时用文字、描边或图标表达 |

保留系统深浅色跟随和标准安全区。反馈文案明确当前结果及可用下一步，避免在错误提示中暴露文件路径或凭据。相机取景、旅行时间线、成员资料卡和年度格子共享颜色、间距和文字样式，同时保留各自的内容密度。

## 8. 实施与验收

1. **共用样式与首页。** 先落地色彩、文字和间距，并用空库、只有媒体、同时有笔记和媒体的三种资料库检查第一屏。确认底栏中央动作在任意页面打开和取消都能返回原位置。
2. **拍摄到归档。** 真机测试自动拍摄、手动拍摄、低光、识别失败、重拍和相机权限拒绝。验证新增成员后自动选中，保存前调整日期，退出校正后表单值仍保留。
3. **笔记、收藏和成员。** 用一个跨天旅行串联多场 Live、独立合影回忆与视频。验证草稿恢复与 Markdown 预览。为成员设置两个相同应援色并再次编辑，验证收藏页和归属选择器一致。点击格子日期能筛选，并能一键清除。
4. **设置与异常恢复。** 分别演练离线、指纹变化、远端空库、远端已有数据、附件缺失及修改冲突。验证本地内容始终可找回，并且不会误切换或覆盖现有资料库。
5. **走查与跨平台。** 用小屏 iPhone、常规 iPhone 与 iPad 验证浅深色、最大无障碍字号、VoiceOver、减弱动态效果及中日文输入。macOS、Android、Windows 共享视觉规则、数据术语和流程状态，容器、导航与交互控件按各自平台适配。
