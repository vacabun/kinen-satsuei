# 記念撮影｜手机笔记卡片编辑器交互设计

2026-11-21 · 设计提案

## 1. 设计目标

把手机上的笔记变成一列可组合的卡片。用户可以马上写一段回忆，在合适的位置插入照片、视频或行程，也能用拖拽整理顺序。沿用应用的黑白配色、柔和圆角、成员头像和应援色。每张卡片的结构服从内容，少用常驻按钮，把编辑空间留给文字与影像。

现有编辑器把正文放在一个 Markdown 文本框里，媒体靠菜单插入或逐项勾选。改版后，正文默认进入卡片编辑模式，关联媒体时打开独立页面。阅读页继续以连贯的笔记排版呈现卡片内容。

## 2. 编辑器布局

```text
返回            编辑笔记              完成
[ ＋ 插入 ]        [ 预览 ]        [ 更多 ]
─────────────────────────────────────────
大阪旅行                        笔记信息 ›
11 月 21–23 日 · 旅行

⠿   出发前                         ⋯
    写一段当时的回忆……

⠿   [拍立得] [合影] [视频 0:18]      ⋯
    3 项媒体

⠿   11 月 22 日   大阪 Live        🔒

＋ 在末尾添加
```

- 顶部操作栏在滚动时保留「插入」「预览」「更多」。「完成」提交笔记，返回时保存草稿。保存进度在顶部轻量提示，保存失败提供重试并保留编辑状态。
- 笔记标题固定在内容区顶部。日期、类型、地点、上级笔记和封面集中到「笔记信息」。普通卡片通过细线和留白分隔，媒体卡使用更明显的背景。激活卡片用描边提示，锁定卡片用锁图标和「已锁定」提示。
- 新笔记进入后可直接写标题或第一段。点文字进入当前卡片编辑，其他卡片留在阅读状态。确认键照常换行，新增卡片通过顶部「插入」或末尾入口。中文和日文输入法正在组合文字时，先完成输入再变更卡片位置或类型。
- 预览保持当前阅读位置，隐藏拖拽柄与编辑操作。返回编辑后恢复当前卡片与滚动位置。

## 3. 插入、排序与滑动操作

### 插入卡片

顶部「插入」弹出半高菜单，优先列出常用类型。目标位置写在菜单顶端，例如「插在『出发前』之后」。有当前卡片时插在它后面，没有当前卡片时插在文末。点卡片边界的插入位可将菜单定位到两张卡之间。插入文本后立即聚焦，插入媒体则先进入选择页。取消选择时保留原来的插入位置，避免产生空卡。

| 卡片 | 编辑时的行为 |
| --- | --- |
| 段落、标题、引用 | 点正文直接编辑。标题级别与引用样式由卡片类型决定 |
| 项目列表、编号列表 | 同一张卡内编辑多项，卡片整体参与排序 |
| 照片、视频、媒体组 | 单选生成一张媒体卡，多选生成一张媒体组卡；卡内可查看、补选和重排 |
| 分隔线 | 占据一个可拖动位置，在阅读页只显示细线 |
| 行程项、关联笔记 | 旅行笔记可插入行程项；能建立合法关系的 Live、旅行或合影回忆可插入关联笔记卡 |

### 拖拽排序

每张卡左侧提供拖拽柄，长按后抬起卡片。移动中用横线明确标出插入位置，靠近屏幕上下边缘时自动滚动。放下后保存新顺序并提供「撤销」。放手位置无效时卡片回到原处。不在正文上启动拖拽，以免干扰光标与文本选择。

「更多」与 VoiceOver 操作提供「上移」「下移」和「移到指定卡片前后」。锁定卡片仍可通过拖拽柄或移动命令重新排序，锁定的范围是卡片内容与删除保护。

### 滑动与锁定

卡片向左短滑，右侧露出「锁定／解锁」与「删除」两个按钮。滑动从卡片中部开始，保留系统从屏幕左边缘返回的手势。滑到最远也只露出操作。正在编辑的卡片先退出输入状态，再接受横向滑动。媒体组的横滑发生在缩略图内部，卡片操作发生在标题区域。卡片「更多」菜单提供同样的动作。

| 状态 | 编辑与删除 |
| --- | --- |
| 未锁定 | 可编辑内容。点「删除」后移出正文，并显示「已删除卡片 · 撤销」 |
| 已锁定 | 可选中复制文字、播放视频和移动整张卡。编辑内容前需显式解锁。点「删除」打开确认框，明确标题或类型，并默认选中「取消」 |
| 已移除的媒体卡 | 移除的是当前笔记里的引用。确认文案提示照片或视频仍保留在资料库，可重新关联 |

撤销会恢复卡片内容、位置和锁定状态。解锁同样需要点按钮，浏览、拖动或预览时不会自动解除。锁定状态随草稿、已完成笔记和资料库备份保存。

## 4. 独立的媒体选择页

从「插入 → 媒体」进入全屏选择页，也可从现有媒体组的「添加媒体」进入同一页面。顶部显示「取消」「选择媒体」，底部固定显示已选数量和确认按钮。

```text
取消                选择媒体
[ 搜索成员、日期或媒体备注          ]
[ 按成员 ]               [ 按时间 ]
[ 全部类型 ▾ ]           [ 已选 3 ]

成员 / 团体，或 年月 / 日期范围
[ 拍立得 ① ]  [ 合影 ]      [ 视频 ② ]
[ 照片 ]      [ 拍立得 ③ ]  [ 照片   ]

          [ 插入 3 项媒体 ]
```

| 浏览方式 | 交互 |
| --- | --- |
| 按成员 | 先显示带头像和应援色的成员列表，也可切换团体或「未标记成员」。进入某个成员后显示匹配网格，按拍摄时间倒序。多人合影在每个相关成员下都可找到 |
| 按时间 | 默认按拍摄时间倒序，按月分组，可跳到指定年月或选择日期范围。提供切换「入库时间」，拍摄日期缺失的项目放在独立的「日期未知」分组 |
| 搜索和类型 | 搜索成员、团体、日期及媒体备注。类型筛选包括拍立得、合影、照片和视频。清空筛选时继续保留已选媒体 |

- 点缩略图选择，圆点中的数字表示插入顺序。提供独立的预览操作供辨认相似照片和播放视频。已选项目跨成员、时间和搜索结果保持，可以在「已选」清单中移除或调整顺序。
- 同一个媒体 ID 一次只选一次。已经在当前笔记中使用的项目标为「已关联」，仍可显式插入到另一个位置，收藏计数按唯一媒体记录计算。
- 「插入媒体」会在原位置生成媒体卡并关联对应媒体；「添加到媒体组」追加到原卡。笔记信息中的「仅关联媒体」入口也使用此页，确认后媒体出现在笔记附件区。
- 缺少本地文件的媒体记录显示占位和原因，仍可选为引用。日期未知的媒体可通过入库时间或成员找到。取消页内选择时，正文及已有媒体保持原样。

## 5. 文档、草稿和兼容性

Markdown 继续作为正文的可移植格式。卡片有稳定 ID，重排后保持 ID。类型、锁定状态与正文的对应关系记录在笔记元数据中，随 Git 同步及备份携带。媒体引用继续使用现有媒体 ID，移动卡片时不会复制照片和视频。

旧笔记首次打开时按段落、标题、列表、引用和媒体引用生成卡片。保留无法识别的 Markdown 内容为一张可编辑的 Markdown 卡，用户确认保存后才写入新的结构信息。纯 Markdown 导出保留正文、卡片顺序和链接。完整资料库导出同时保留卡片 ID 与锁定状态。外部 Markdown 编辑导致某张锁定卡无法对应时，提示检查并保留原版本供确认。

同步时用稳定 ID 识别两端的卡片。同一卡片的重叠修改、删除与编辑相遇、两端对同一区域重排时进入冲突处理，保留可预览的两个版本。草稿仅在本机保存，完成之前可以从笔记列表继续编辑。

## 6. 验收场景

1. 从一篇旧 Markdown 笔记打开编辑器，依次插入标题、回忆和三张媒体，拖动媒体组到第一段之后，重新打开仍保持顺序。
2. 锁定文字卡，尝试编辑应出现解锁入口。拖动锁定卡后，内容和锁仍保留。滑动删除时先显示确认，取消后卡片仍在。
3. 分别从成员、拍摄日期、入库日期和「日期未知」选图。切换浏览方式和筛选后核对已选顺序，取消时验证原笔记无变化。
4. 在键盘打开、小屏、大字体和 VoiceOver 下，验证插入、移动、锁定与删除都可以完成。照片和视频缩略图用文字辅助辨认类型与选择状态。
5. 在拖拽、选择媒体或编辑中断后返回，核对已完成的编辑和草稿。验证备份恢复后仍保留卡片顺序、锁定和媒体关联。
