# 記念撮影｜产品与 iOS 交互设计

- **日文** 記念撮影（きねんさつえい）
- **罗马音** kinen satsuei
- **中文** 纪念摄影

## 1. 产品目标

用一次尽量短的操作保存一张拍立得，也能在之后补写合影当时的心情，把同一天的媒体、Live 和旅行串成可翻阅的手帐。应用首次启动即可离线使用，用户可在设置中接入自己的 Git 仓库。

首版采用中文界面，显示日文应用名。支持录入中日文成员名、标题和正文。iPhone 优先，界面采用适配屏幕宽度的原生导航。

## 2. 信息架构

| 底栏入口 | 内容 |
| --- | --- |
| 首页 | 最近的手帐、最近媒体、成员收藏入口，支持按类型、成员和日期过滤 |
| 手帐 | 草稿、已保存的手帐，以及创建入口 |
| ＋ | 居中的主按钮，立即弹出添加面板，关闭面板返回原页面 |
| 收藏 | 成员收藏、拍立得网格和趋势统计 |
| 设置 | 成员管理、存储空间、Git 同步、资料库导入与导出 |

底栏采用五个等宽位置，让添加按钮保持居中。左侧是首页和手帐，右侧是收藏和设置。首页的成员卡片与收藏入口指向同一个统计页面。

首页从上往下显示手帐本、最近媒体、成员收藏。手帐卡片使用封面或首个可用图像、标题、日期和类型。媒体网格以缩略图为主，视频角标显示时长。空库给出“添加第一张拍立得”和“写一篇手帐”。翻阅详情时保留返回位置。

视觉采用暖白纸面、深色正文和低饱和玫瑰强调色。拍立得卡片使用留白相框，手帐日期与 Markdown 标题有清楚的层次。支持系统深色模式、动态字体和 VoiceOver。选中状态同时使用图标或文本。

## 3. 添加媒体

1. 点中间的“＋”，选择“扫描拍立得”“导入照片或视频”或“拍摄照片或视频”。在 Live 或旅行详情内打开添加面板时预选当前手帐。
2. 扫描优先使用系统文稿相机。对已有照片使用矩形检测建议四个角，可手动调整四角、旋转，并预览透视矫正结果。检测失败时允许手动框选。扫描以整张拍立得的外缘为准，保留下方留白和签名。
3. 批量导入时显示每项的预览和处理状态。可批量套用日期、成员或手帐，也可单项修改。媒体类型为拍立得、合影、照片或视频。多人合影可以选多个成员。
4. 拍摄日期可为当天、手动日期或未知。相册元数据只用于建议，扫描当天与拍立得实际拍摄日可以不同。保存后可修改成员、日期和手帐归属。
5. 确认后将文件复制到应用资料库。保留可取得的源图，矫正图作为默认展示。系统文稿相机提供的帧可能已裁切，界面标明可回退到的扫描源。视频沿用导入文件，详情页提供播放、时长与文件状态。
6. 部分文件失败时保留已成功项并允许重试。取消时清除本轮未保存的临时副本。相机不受支持或权限被拒绝时，仍可从相册导入。

媒体详情显示成员、拍摄日、所属手帐及个人备注。详情页可直接创建一篇合影回忆，或把当前媒体链接到已有手帐。修改或重新矫正同一张实体拍立得保持原媒体 ID。

扫描入口参考 [Apple VisionKit 文稿相机](https://developer.apple.com/documentation/visionkit/vndocumentcameraviewcontroller)。

## 4. 手帐、Live 和旅行

| 记录类型 | 内容 | 可选子项 |
| --- | --- | --- |
| 合影回忆 | 标题、日期、Markdown、拍立得和合影等媒体 | 无 |
| Live | 标题、日期、地点、Markdown、照片和视频 | 多篇合影回忆 |
| 旅行 | 标题、起止日、Markdown、每日行程、旅行照片或视频 | 多场 Live、独立的合影回忆 |
| 普通手帐 | 标题、日期、Markdown 和媒体 | 无 |

每篇记录可以独立存在。用户可先写 Live，再建立旅行并把这场 Live 放进去。旅行详情按日期排列行程、Live 和直属回忆。没有日期的子记录显示在“待安排”。旅行日期改变后，落在范围外的已有记录保留，并标记为待调整。每条记录最多一个直接上级，媒体可以被多篇手帐引用。

例如，用户可建立大阪旅行（周五至周日），在周六下放一场 Live，给 Live 加现场视频，再把原本独立的合影回忆移入该场 Live。首页仍能从最近手帐直接打开这篇合影回忆。

编辑器提供“编辑”和“预览”，可插入标题、列表、引用、分隔线及媒体。Markdown 保存为纯文本，图片和视频引用通过媒体选择器插入。常用格式包含标题、强调、引用、链接、列表及图片。预览以本地媒体为主，外部链接由用户点击打开，远程图片首版显示为链接。编辑中自动保存草稿，点击“完成”后进入已保存手帐。用户可调整封面与媒体顺序。删除旅行或 Live 时，其直接子记录恢复为独立记录。

## 5. 成员收藏与统计

- 成员页显示现有拍立得总量、最近新增、按月趋势及收藏网格。首版趋势按拍摄年月统计，并支持切换看入库年月。
- 拍立得收藏量的单位是一张实体拍立得对应的媒体记录。矫正版本、缩略图和手帐重复引用均使用同一条媒体记录。
- 一张拍立得标注多名成员时，各自成员页各加一张。全库总数按照媒体 ID 去重。删除媒体后，收藏量同步更新。
- 无拍摄日期的记录计入总收藏，归入“日期未知”，不进入拍摄月份趋势。普通合影、照片、视频可单独筛选。
- 成员可重名，通过团体或别名区分。改名保留历史引用。归档成员后，旧照片照常显示该成员，可从设置恢复。

## 6. 设置与关键反馈

设置显示本地空间用量、待同步项与上次成功同步时间。Git 页面包含远程地址、分支、SSH 公钥、连接检查、同步操作、冲突入口及媒体同步选项。恢复流程支持用另一台设备连接同一仓库，先预览仓库内容，再选择导入。用户可手动导出完整资料库，包含 Markdown、元数据与本地媒体。

同步期间仍可以阅读与编辑，编辑会留在下一轮待同步队列。失败状态区分认证失败、主机指纹变更、分支冲突、附件过大和网络中断，显示可操作的处理入口。首次启动和本地保存不要求 Git 账户。
