# 記念撮影 · kinen satsuei

アイドルとのチェキや記念写真、ライブ、遠征の思い出をまとめるアプリです。iOS 版を中心に開発しており、写真や動画と一緒に日記を残せます。記録は端末内に保存でき、必要に応じて自分の Git リポジトリと同期できます。

## リポジトリ構成

| パス | 内容 |
| --- | --- |
| `doc/` | プロダクト設計、データ仕様、アーキテクチャ |
| `apps/ios/` | iOS の Xcode プロジェクト |
| `apps/apple-shared/` | iOS と macOS で共通の Git 設定画面 |
| `apps/macos/` | macOS の SwiftUI プロジェクト |

アプリのソースコードと、利用者が設定する思い出のライブラリは別々のリポジトリで管理します。開発ではテスト用データを使い、実際の写真、動画、ノート、認証情報はアプリのサンドボックスや利用者専用のフォルダに保存してください。

## iOS 版

Xcode で `apps/ios/KinenSatsuei.xcodeproj` を開き、スキーム `KinenSatsuei` と iOS 17 以降の実行先を選びます。シミュレータでは画面や写真ライブラリからの取り込みを確認できます。チェキのスキャンには背面カメラ付きの実機が必要です。実機で起動するには Xcode で自分の署名チームを選択してください。

- **チェキのスキャン**。検出した枠をリアルタイムで表示します。初期設定は自動撮影で、手動に切り替えられます。連続撮影、撮り直し、四隅の補正、回転、露出・コントラスト・彩度の調整、局所的な反射の軽減に対応しています。撮影日とメンバーまたはグループを記録でき、元画像と処理後の画像は個別に保存します。
- **コレクション**。写真や動画を取り込んで、メンバー、グループ、日付などから探せます。チェキの枚数は年ごとのヒートマップと月別の棒グラフで確認できます。撮影日と登録日を切り替えられ、ヒートマップの日付をタップすると、その日のチェキを表示します。
- **ノート**。文章やメディアをカードとして並べ替え、メディアを関連付けられます。旅行、ライブ、思い出は単独でも、親子関係を付けても記録できます。旅行では日ごとに時刻、場所、メモを追加できます。下書きは端末に自動保存されます。Markdown の見出し、リスト、引用、区切り線、コードブロック、ローカルメディア参照をプレビューできます。表は設計段階です。

「設定 → ライブラリ」では、バックアップをフォルダに書き出し、`library.json` を含むフォルダから復元できます。復元先は別のライブラリとして開きます。バックアップには保存済みのノート、メンバー、グループ、メディアの記録、端末にある添付ファイルが含まれます。編集中の下書きは元の端末に残ります。

「設定 → Git」では Ed25519 の鍵を生成または取り込み、SSH でブランチの確認や同期ができます。初回接続時はサーバーの指紋を確認してください。既定ではノートとメタデータを同期し、必要に応じて 95 MiB 以下の添付ファイルも含められます。リモートライブラリは内容を確認してから復元できます。競合時は項目ごとに内容を比較し、採用する側を選んで同期を再試行できます。GitHub や自前のサーバーを利用した iPhone での一連の同期は、引き続き検証中です。

## macOS 版

Xcode で `apps/macos/KinenSatsueiMac.xcodeproj` を開き、スキーム `KinenSatsueiMac` と実行先 **My Mac** を選びます。macOS 14 以降に対応しています。

ノートの閲覧・編集、メディアとコレクションの集計、写真や動画の一括ドラッグ＆ドロップ、iOS と共通のバックアップ形式での書き出し・復元ができます。⌘N でノートを新規作成し、⌘I でメディアを取り込みます。SSH 鍵の生成・取り込み、サーバーの指紋確認、同期・復元には iOS と共通の Git 設定画面を使用します。実機間の同期とドラッグ＆ドロップは引き続き検証中です。

## Android 版

Android Studio で `apps/android/` を開き、Android SDK 35 でビルドします。対応 OS は Android 10 以降です。同じディレクトリで `./gradlew assembleDebug lintDebug` も実行できます。

iOS や macOS から書き出したライブラリを復元し、ノート、旅行の行程、関連メディア、メンバーやグループごとのコレクションを閲覧できます。ノートの作成・編集、メディアの関連付け、端末内への下書きの自動保存にも対応しています。下部の追加ボタンから写真や動画をまとめて選んだり、システムのカメラでチェキを撮影したりできます。SSH 同期とチェキの四隅補正は今後の対応予定です。

## Windows 版

.NET 10 SDK と Go 1.27.4 をインストールし、`go` に PATH を通してから、リポジトリのルートで実行します。

```sh
dotnet run --project apps/windows/Kinen.Windows/Kinen.Windows.csproj
```

ライブラリの復元、ノート・行程・メディア・チェキの検索と閲覧、ノートの作成・編集、下書きの自動保存、メディアの関連付け、バックアップの書き出しに対応しています。写真や動画はファイル選択やドラッグ＆ドロップで取り込めます。チェキはメンバーまたはグループごとに整理できます。

Git では、SSH のリポジトリ URL とブランチ、秘密鍵を指定し、サーバーの指紋を確認してから、リモートのバックアップを別ライブラリとして復元できます。空のブランチには、ノートとメタデータを初回バックアップとして送信でき、写真や動画の追加も選べます。接続設定をライブラリごとに保存でき、秘密鍵とパスフレーズは現在の Windows ユーザーの DPAPI で保護されます。

リモートのブランチが前回のバックアップまたは復元時点のままであれば、既存のバックアップを更新できます。メタデータだけを送信する場合も、リモートで引き続き参照されている添付ファイルは保持されます。サーバーの指紋が変わった場合は、変更を確認し、以前の接続設定を削除してから再登録してください。カメラ撮影、リモートの変更のマージ、双方向の SSH 同期は今後の対応予定です。

共通データ形式のテストは次のコマンドで実行できます。

```sh
dotnet run --project apps/windows/Kinen.Windows.Tests/Kinen.Windows.Tests.csproj -- fixtures/library-v1
```

## GitHub Actions とリリース

ブランチへのプッシュやプルリクエストごとに、iOS、macOS、Android、Windows のビルドと対象のテストが実行されます。手動実行では、公開前に各パッケージを Actions の Artifacts から確認できます。

Git タグをプッシュすると、4 プラットフォームのパッケージがそろった時点で、同じタグの GitHub Release が公開されます。

```sh
git tag v0.1.0
git push origin v0.1.0
```

公開済みのパッケージは、リポジトリの [Releases](https://github.com/vacabun/kinen-satsuei/releases) からダウンロードできます。

| 対象 | ファイル | 配布形式 |
| --- | --- | --- |
| iPhone | `KinenSatsuei-unsigned.ipa` | 未署名。通常の iPhone にインストールするには Apple の署名が必要 |
| iOS シミュレータ | `KinenSatsuei-simulator-arm64.zip` | Apple Silicon Mac 向け。展開後に `.app` をシミュレータへインストール可能 |
| macOS | `KinenSatsuei-macos-arm64.zip` | Apple Silicon Mac 向け。アドホック署名済み、公証なし |
| Android | `KinenSatsuei-android-unsigned.apk` | リリースビルド。配布には署名が必要 |
| Android | `KinenSatsuei-android-debug.apk` | デバッグ署名済みの動作確認用。同じ鍵で署名されたビルドのみ上書きインストール可能 |
| Windows | `KinenSatsuei-windows-x64.zip` | .NET ランタイムを同梱。展開後に `KinenSatsuei.exe` を起動 |
